# 梁永琦航空轮胎摩擦磨损实验入库报告

## 1. 数据集概况

- 数据集编号：`TIRE-EXP-LYQ-FRICTION-001`
- 数据来源：团队授权实验资料 `E:\梁永琦`
- 领域：航空轮胎胎面橡胶摩擦磨损
- 用途：知识检索、案例训练、工况判读、比赛展示
- 安全边界：实验室小试数据不直接构成维修或适航限值

## 2. 可用内容

| 维度 | 正式化结果 |
| --- | --- |
| 接触方式 | 柱-面、球-面、环-块 |
| 温度工况 | 15、40、60、80、100 °C |
| 接触应力 | 1.2、1.5、1.8 MPa 柱-面主试验 |
| 滑动距离 | 20、40、80、120、160 m |
| 定量记录 | 5 组温度、15 组载荷-距离、18 条接触摩擦曲线 |
| 图像证据 | 17 张 SEM、3D-OM、光学图和结果图 |
| 原始曲线 | 15 条温度曲线及环-块、球-面摩擦曲线 |

## 3. 主要专业结论

1. 接触应力增加会提高界面温度和磨损质量，并加剧硬度下降与撕裂。
2. 温度由 15 °C 升至 100 °C 时，摩擦系数整体上升，磨损率先增加后趋稳，原始温度曲线最高值达到 126.7 °C。
3. 损伤形貌由平行滑动方向的犁沟逐渐演化为犁沟与垂直方向山脊状条纹并存。
4. 磨损机制由磨粒磨损逐渐转为磨粒-疲劳复合磨损，高温下氧化降解作用增强。
5. 三种接触方式具有不同模拟边界，可用于训练实验方案选择和损伤形貌判读。

## 4. 来源差异

- 环-块载荷在单个标号表中写为 75 N，但论文、磨损表和 70xx 曲线均支持 70 N，正式记录采用 70 N。
- `9067` 曲线实际只运行 67 min，短于 75 min 方案，标记为 `partial_duration`。
- 温度标号表存在复用的“200 r/min”文字，正式温度工况以论文明确的柱-面往复 3.3 Hz 为准。
- 不同接触方式磨损表未写明单位，保留为源附件，不用于定量生成。
