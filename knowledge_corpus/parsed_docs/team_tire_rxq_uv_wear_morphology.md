# 航空轮胎胎面橡胶紫外老化后摩擦形貌证据

## 训练与审核边界

1. 先按裂纹、沟槽、剥落、磨屑和表面粗糙化等可见事实描述，不从单图直接判定机理。
2. 跨时长比较时保持图像角色和尺度标签一致；不把亮度差异直接解释为老化程度。
3. 机理结论须与拉伸、硬度、FTIR 或已确认摩擦工况交叉验证。
4. 若摩擦参数未补齐，审核 Agent 应输出证据不足并要求补录，而不是生成确定性因果结论。
