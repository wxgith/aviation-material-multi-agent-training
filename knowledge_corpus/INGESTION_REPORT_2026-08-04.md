## 3. 证据链

1. 官方来源页用于核验发布机构、文档编号和公开状态。
2. 原始 PDF 保存至 `raw_docs/`。
3. `source_registry.json` 保存 URL、许可说明、适用章节、页码范围和 SHA-256。
4. `pdf_parser` 仅解析专业相关页，并在 Markdown 中保留 `Page N`。
5. `chunker` 添加中英领域标签，包括轮胎欠压、事故案例、跑道工况、刹车检查、剪切散斑检测和冲击后剩余强度。
6. `pipeline` 生成 JSON chunks、更新 manifest 并写入 Elasticsearch。

## 4. RAG 多样性增强

检索结果新增来源多样性重排：保持 BM25 原始排序，但在来源充足时限制同一文档最多占两个证据位。这样前五条证据可以同时包含教学基础片段、同行评审论文、官方维修手册、事故报告或实验报告，减少单篇长文占满全部证据位的问题。

## 6. 质量边界

FAA AC 65-15A 属于历史维修手册，只用于基础原理和检查流程训练；真实机务操作必须以当前有效的机型 AMM、CMM、适航指令和单位批准程序为准。事故报告用于学习因果分析和维护决策，不应脱离具体机型与运行条件直接泛化。所有机器解析片段仍需专业教师抽检。
