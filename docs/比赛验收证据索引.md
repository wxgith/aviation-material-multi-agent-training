## 二、自动测评命令

```powershell
cd D:\agents\backend
.\.venv\Scripts\Activate.ps1
python -m app.evaluation.runner
pytest
```

运行后重点保存：

- `evaluation/automated_results.json`：机器可读明细；
- `evaluation/automated_summary.md`：答辩和提交使用的摘要；
- `evaluation/expert_review_form.md` 或专家复核工作簿：人工专业结论。

## 三、人工证据边界

自动结果只能证明结构完整性、规则一致性和来源登记情况。核心知识点覆盖率、幻觉率、难度适配准确率及维修结论边界已由项目团队领域专家组复核，并由项目负责人电子确认；自动指标不替代该专家结论。
