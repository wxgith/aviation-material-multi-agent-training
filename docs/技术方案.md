# 技术方案

## 技术栈

- 前端：React + Vite
- 后端：FastAPI
- 数据：本地 JSON 知识库、题库和学习者画像
- LLM：默认 mock/template 模式，预留 OpenAI-compatible 环境变量

## 后端模块

- `api/routes.py`：统一接口入口
- `models/schemas.py`：Pydantic 数据模型
- `services/data_loader.py`：本地 JSON 加载
- `services/diagnosis_service.py`：诊断评分
- `services/retrieval_service.py`：知识片段检索
- `services/resource_service.py`：个性化资源生成
- `services/report_service.py`：学情报告与 Markdown 导出
- `agents/`：6 个 Agent 与 orchestrator

## 前端模块

- `src/api/client.js`：统一 API 客户端
- `src/main.jsx`：页面流程与状态管理
- `src/styles/app.css`：基础布局和展示样式

## 数据结构

系统数据位于 `backend/app/data/`，包括画像、诊断题、三个知识库和固定演示案例。知识片段包含标签、难度、来源类型、适用学习者和常见误区，便于后续升级为向量检索。

## 运行与测试

后端通过 `uvicorn app.main:app --reload --host 0.0.0.0 --port 8000` 启动，前端通过 `npm run dev` 启动。后端测试使用 pytest，前端构建使用 `npm run build`。
