# 录屏运行手册

## 1. 推荐模式

录屏前按下列优先级选择模式：

1. SQL + ES + Qwen：仅在 `demo_preflight.ps1 -WarmDemo -WarmLlm` 全部通过后使用，重点展示动态生成和审核门。
2. SQL + ES + mock：正式稳定模式，展示真实持久化、ES 检索和完整 6 Agent 闭环。
3. JSON + mock：Docker 或网络异常时的现场兜底。

不要在开始录制后临时修改 `.env`。切换模式后必须重启后端并重新访问 `/api/health`。

## 2. 启动与预检

```powershell
cd D:\agents
.\scripts\start_project.ps1 -NoBrowser
.\scripts\demo_preflight.ps1 -WarmDemo
```

准备展示真实 Qwen 时使用：

```powershell
.\scripts\demo_preflight.ps1 -WarmDemo -WarmLlm
```

只有输出 `Demo preflight READY` 后再开始录屏。预检报告位于 `outputs/demo/demo_preflight_latest.json`。

## 3. 9 分钟录制路线

| 时间 | 操作 | 重点 |
| --- | --- | --- |
| 0:00-0:35 | 打开 `/api/health` | SQL、ES、LLM/mock、fallback 状态 |
| 0:35-1:10 | 首页和全局助手 | 不是单一聊天页；助手理解当前页面和学情 |
| 1:10-1:40 | 加载演示案例 | 本科生、航空轮胎、热氧老化与滑动磨损 |
| 1:40-2:30 | 提交诊断 | 得分、薄弱点、画像差异 |
| 2:30-3:40 | 展示 6 Agent 进度 | 当前 Agent、进度、预计时间、输入输出摘要 |
| 3:40-4:30 | RetrievalAgent | Elasticsearch、Hybrid、标题、evidence_id |
| 4:30-5:50 | 四类资源 | 动态讲义、实操指南、分阶测试、案例任务 |
| 5:50-6:35 | 审核纠偏 | Qwen 原始候选 3/6 被驳回并证据模板重生 |
| 6:35-7:20 | 学情报告与导出 | 路径、难度、建议、Markdown 报告 |
| 7:20-8:00 | 反馈与动态追问 | next_action 更新，答案绑定证据和边界 |
| 8:00-8:40 | 60 N、160 m 案例 | 工况、趋势图、图像、证据 ID、限制 |
| 8:40-9:10 | 工程与测评证据 | MySQL、ES 1,766、110 tests、50/50、15/15、39/39 |
| 9:10-9:25 | 总结 | 可运行、可验证、可迁移；JSON/mock 兜底 |

测试数字以提交前 `competition_baseline.json` 为准；上表中的测试数不是永久常量。

## 4. 录屏前人工检查

- 浏览器缩放 100%，分辨率 1920×1080，关闭无关标签页和系统通知。
- 首页不得出现“后端接口不可用”横幅。
- Agent 进度开始后不要连续重复点击提交。
- 预先打开 DBeaver 表列表和 ES `_cat/indices`，不在镜头中输入密码。
- 不展示 `.env`、API Key、数据库密码或浏览器开发者工具中的敏感请求头。
- 导出报告前清空浏览器下载栏中的无关文件。

## 5. 失败切换

- Qwen 超时或失败：停止录制，设 `LLM_ENABLED=false`，重启后端，重新跑 `-WarmDemo`。
- ES 异常但 MySQL 正常：可演示 JSON fallback，但需在视频中如实说明当前检索源。
- Docker 不可用：使用 JSON + mock 模式，并保留已有 SQL/ES 验收截图作为工程证据。
