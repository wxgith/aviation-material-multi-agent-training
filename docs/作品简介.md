# 作品简介

《面向航空工程材料损伤分析的多智能体个性化知识生成与实操训练系统》是一套面向航空工程学院学生、材料方向研究生、科研训练新手和航空维修岗位学习者的垂直领域 Web 训练平台。系统围绕航空材料服役损伤识别、机理分析、实验表征和维护判读等典型任务，首期覆盖航空轮胎胎面橡胶、航空刹车摩擦材料和飞机复合材料板三个方向。

航空工程材料损伤分析具有专业门槛高、知识与工况强关联、实验约束严格、结论边界敏感等特点。传统教材难以根据学习者基础实时调整内容，通用聊天模型又容易脱离试验条件给出过度确定的判断。为此，本系统以“学情画像构建—多智能体协同调度—领域知识检索—个性化资源生成—专家审核纠偏—反馈决策更新”为主线，将一次性问答转化为可观察、可追溯、可迭代的训练闭环。

用户可选择本科低年级学生、材料方向研究生或机务维修新员工等画像，填写专业背景、学习目标和训练方向，并完成方向化诊断题。系统根据得分、强弱知识点和目标启动六个职责明确的 Agent：学情诊断 Agent 识别知识盲区，材料路由 Agent 选择专业知识域，知识检索 Agent 从 Elasticsearch 获取证据，资源生成 Agent 组织讲义、实操指南、分阶测试题和案例任务，审核纠偏 Agent 检查概念、证据一致性、难度和操作边界，学习路径决策 Agent 给出下一步训练计划。各步骤均展示输入摘要、输出结果、置信度、证据 ID 和运行状态。

系统已形成从原始资料登记、Markdown 解析、知识切片、索引清单到 Elasticsearch 入库的知识库构建证据链。当前索引包含 1,766 条可追溯知识切片，关联 4 个团队实验专题、53 项已审核实验资产，并补充公开论文、FAA/NASA 等公开资料。学习过程数据写入 MySQL，可在 DBeaver 中验证诊断记录、Agent 会话、中间步骤、生成资源、学情报告和反馈记录。MySQL 或 Elasticsearch 不可用时，系统自动回退本地 JSON；外部模型异常时，稳定模板仍可完成主训练流程。

在交互层，系统接入 OpenAI-compatible 的 Qwen 调用，用于基于当前画像、诊断结果和 RAG 证据的开放动态追问。回答需经过证据绑定、结构校验和审核纠偏，页面如实标注真实模型或模板兜底状态。正式演示采用“真实 Qwen 问答 + 证据约束模板资源”的稳定组合，既体现自然语言理解和动态生成能力，也避免网络波动中断完整闭环。

目前项目已通过 116 项后端自动化测试和前端生产构建，50 条核心用例完整执行 50/50 通过，并具备报告导出、数据库持久化、知识证据展示、异步进度反馈和 JSON/mock 兜底能力。系统可用于航空工程材料课程辅助教学、科研入门训练、实验前预习和维修岗位案例训练，后续可扩展 BGE 向量检索、更多航空材料专题及真实学习效果验证。
