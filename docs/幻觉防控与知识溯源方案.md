# 幻觉防控与知识溯源方案

## 1. 垂直领域生成为什么容易出现幻觉

航空工程材料损伤分析涉及材料结构、服役环境、实验表征、维修判读和安全边界。普通生成式系统容易在以下场景出现幻觉：

1. 将一般材料知识套用到航空轮胎、刹车片或复合材料板的具体工况。
2. 缺少证据时直接给出损伤等级或维修结论。
3. 混淆实验训练建议和真实适航放行结论。
4. 忽略工况参数、检测方法、图像尺度和服役历史。
5. 对学习者基础估计错误，生成难度不匹配的资源。

## 2. 知识库检索如何约束生成

系统在资源生成前先由 RetrievalAgent 检索领域知识片段。检索输入包括：

- 学习者画像；
- 训练方向；
- 学情诊断薄弱点；
- 当前学习目标。

检索输出包括：

- `evidence_ids`
- `evidence_titles`
- `retrieval_scores`
- `retrieval_mode`
- `knowledge_source`

GenerationAgent 应围绕这些证据片段组织讲义、实操指南、测试题和案例任务，避免凭空扩展。

## 3. evidence_ids 如何绑定生成内容

每个知识片段具有稳定 ID，例如：

- `tire-k01`：热氧老化与橡胶交联网络变化；
- `tire-k06`：热氧老化-滑动磨损耦合边界；
- `brake-k04`：失效机理证据链；
- `composite-k03`：无损检测图像判读。

Agent 步骤中会返回 `evidence_ids`。报告、审核和后续人工复核可依据这些 ID 追溯到知识库切片和 `knowledge_corpus/index_manifest.json`。

## 4. 审核纠偏 Agent 的交叉验证

ReviewAgent 主要检查：

1. 是否存在专业概念错误；
2. 是否与知识库依据不一致；
3. 是否难度不匹配；
4. 是否过度泛化；
5. 是否缺少实操约束；
6. 是否把训练建议误写成真实适航或维修结论。

审核结果会输出风险点、纠偏建议和依据片段，用于降低幻觉风险。

## 5. 证据不足时如何降级输出

当检索结果不足、ES 不可用或证据片段无法支撑结论时，系统采用降级策略：

1. 从 Elasticsearch 回退到本地 JSON fallback；
2. 从 hybrid/vector 回退到 BM25；
3. 将结论型表达改为“训练建议”或“需补充检测”；
4. 提示缺失的工况参数、检测方法或样本信息；
5. 避免输出真实维修放行结论。

## 6. 如何计算幻觉率

人工抽检生成内容中的专业断言，将断言分为：

- 有知识库依据且表达正确；
- 有知识库依据但表达不严谨；
- 无知识库依据；
- 与知识库或专业常识冲突。

计算方式：

```text
幻觉率 = 无依据或错误断言数量 / 抽检专业断言总数
```

建议在 50 条评测用例中对讲义、指南、案例任务和审核意见进行抽检。

## 7. 人工专家复核流程

1. 选择评测用例；
2. 运行系统并导出报告；
3. 查看 RetrievalAgent 的 `evidence_ids`；
4. 对照 `knowledge_corpus/index_manifest.json`；
5. 使用 `evaluation/expert_review_form.md` 记录问题；
6. 汇总到 `evaluation/eval_results.md`。

专家复核重点不是追求所有表达完全等同原文，而是确认专业逻辑、训练边界和证据链是否可靠。
