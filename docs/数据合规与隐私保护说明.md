# 数据合规与隐私保护说明

## 1. 当前系统使用模拟学习者画像

当前比赛原型内置的学习者画像均为模拟数据，包括本科低年级学生、材料方向研究生和机务维修新员工，不对应真实个人。

## 2. 不存储敏感身份信息

系统不要求也不存储真实身份证号、手机号、家庭住址、学号、证件照等敏感信息。学习者字段仅用于训练画像和学情分析。

## 3. 真实部署时的数据脱敏

如果后续接入真实班级、实验室或岗位培训数据，应对以下信息进行脱敏：

- 学号、工号、手机号；
- 真实姓名；
- 具体单位和设备编号；
- 维修记录中的敏感字段；
- 未公开实验数据。

## 4. 交互日志用途

诊断记录、Agent 会话、生成资源、学情报告和反馈记录仅用于：

- 学习分析；
- 教学改进；
- 系统效果评估；
- 训练路径优化。

不得用于与学习目标无关的评价或商业用途。

## 5. 删除与匿名化

真实部署时应支持：

- 按学习者删除历史记录；
- 将学习者 ID 匿名化；
- 导出个人学习记录；
- 限制管理员访问权限；
- 定期清理过期日志。

## 6. 知识库资料合规

知识库资料应来自：

- 公开文献；
- 授权课程资料；
- 已取得明确授权并完成脱敏的课题组实验资料；
- 已脱敏、已授权的案例材料。

不应直接上传受版权限制的教材全文、企业维修手册全文或未授权内部资料。

当前制动与复合材料方向没有团队实验数据，系统只使用公开论文、公开技术报告和开放数据集可核查内容。界面与报告统一使用“论文试验显示”“报告记录”或“公开数据集包含”等表述，不使用“本系统实测”或“团队试验表明”。机器提取的实验卡必须保留来源链接、原文定位、证据 ID 和限制说明；当前 5 张卡已完成人工复核，未来新增卡片在复核前不得标记为已审核证据。

## 7. 比赛原型边界

当前系统用于航空工程材料损伤分析训练演示。系统输出的检查建议、风险提示和学习路径不能替代真实适航审查、维修放行或工程安全决策。
