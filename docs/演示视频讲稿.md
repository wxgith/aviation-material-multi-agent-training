# 演示视频讲稿

预计时长：9 分 20 秒左右。录制前先用一键脚本启动并确认状态为 `READY`，再打开健康检查页面开始计时。

## 0:00-0:30 工程状态

这里是系统健康检查。当前数据模式为 SQL，MySQL 和 Elasticsearch 均已连接，知识来源为 Elasticsearch。生成模式保持 mock，以避免网络和模型波动影响比赛演示。当前知识库包含 4 个团队实验专题、53 项已审核实验资产和 1,766 条 ES 切片。

## 0:30-1:00 首页与系统定位

前端首页展示航空轮胎、航空刹车片和复合材料板三个训练方向。这里打开全局智能助手并提问“我第一次使用应该从哪里开始？”。助手能够识别当前处于首页，结合训练方向和会话状态给出操作引导；进入专业问题后，则会调用检索、讲解、审核和决策 Agent。系统不是普通聊天机器人，而是按照学情诊断、知识检索、资源生成、专业审核、路径决策和反馈更新组织训练过程。

## 1:00-1:25 加载本科生主线

现在点击“加载演示案例”。系统自动填充本科低年级学生画像、航空轮胎方向，以及理解热氧老化与滑动磨损机理并完成基本损伤判读的学习目标。

## 1:25-2:10 提交诊断

诊断题由后端按材料方向提供。提交后，系统计算得分和水平，识别基础概念、损伤机理与实验表征等薄弱点，将静态画像和当前学情结合起来。

## 2:10-3:20 展示六个 Agent

提交后，页面先显示当前处理 Agent、完成比例、已用时间和预计剩余时间，避免生成期间出现无反馈等待。这里依次展示六个职责明确的 Agent。诊断 Agent 分析薄弱点，路由 Agent 选择材料知识库，检索 Agent 从 Elasticsearch 获取依据，生成 Agent 形成四类资源，审核 Agent 检查专业性和使用边界，决策 Agent 输出学习路径。每一步都有输入摘要、输出摘要、置信度、证据 ID 和实际耗时。

## 3:20-4:40 展示个性化资源

系统针对本科低年级学生生成降维版讲义、胎面损伤检查实操指南、五道分阶测试题和裂纹或剥落案例任务。资源不是自由问答结果，而是由学习者画像、诊断薄弱点和检索证据共同约束。

## 4:40-5:30 展示审核纠偏

审核 Agent 会检查知识依据一致性、难度匹配、过度泛化和实操约束，并给出风险点与纠偏建议。证据不足时，系统会明确限制并降级表达，避免将单张图像或单次记录扩大为确定性工程结论。

## 5:30-6:20 报告、导出与反馈

学情报告汇总画像、诊断得分、知识盲区、资源难度、学习路径和下一步建议。这里点击“导出学情报告”下载 Markdown 文件。随后提交反馈测试，系统根据正确率更新后续动作，本演示路线得到“补充案例并继续巩固”的建议。

## 6:20-6:40 加载工程检索案例

现在返回首页，点击“加载工程检索案例”。这条短路线仍使用本科低年级学生画像，但将目标固定为 60 N、160 m 圆柱-平面往复摩擦证据检索。确认自动填充后直接提交诊断。

## 6:40-7:45 展示 ES 工况命中

在 RetrievalAgent 中可以看到知识来源为 Elasticsearch。TOP 1 和 TOP 2 都来自载荷-距离训练矩阵，其中 TOP 1 证据 ID 为 team_tire_lyq_load_distance_matrix-c001-84f52425。对应工况为 60 N、160 m、1.8 MPa，行程 10 mm，频率 3.3 Hz；记录磨损量为 0.1605 g，硬度为 46.57 HA。

## 7:45-8:20 展示趋势、图像和边界

这里同时展示载荷-距离趋势图与 60 N、160 m 代表性光学形貌。系统把实验图像、定量记录、证据 ID 和限制说明绑定在一起。需要说明的是，该矩阵单元没有可用温升证据，代表性视野也不能替代重复试验和多视野统计。

## 8:20-8:50 展示持久化与索引

完整流程完成后，DBeaver 中可以看到诊断、Agent 会话、六步输出、资源、报告和反馈记录。Elasticsearch 的索引计数为 1,766，说明知识检索不是前端静态数据。

## 8:50-9:05 展示验收结果

当前后端自动化测试为 116 passed，前端生产构建通过；50 条核心用例已逐条进入 6 Agent 管线并全部通过，15 条动态追问专项和 39 条全局上下文助手专项在 JSON 与 Elasticsearch 模式下也全部通过。真实 Qwen 6 个代表性场景机器检查 6/6 通过；配对对照中，原始候选直接通过 3/6，审核驳回并用证据模板重生后通过 6/6。项目团队复核确认的是既有核心用例；新生成回答和学习效果仍需外部专家与真实用户验证。知识证据库还新增了 FAA 2023 维修手册的两个定向摘录：复材无损检测和航空刹车检查维护。这里强调，论文用于解释机理，官方手册用于约束训练操作；具体机型仍以现行制造商批准资料为准。6 条维修专项检索全部命中并可追溯。

## 9:05-9:20 总结

本系统以航空工程材料损伤分析为垂直场景，用多智能体闭环完成个性化训练，用 MySQL 和 Elasticsearch 提供可部署、可验证的工程能力，并用 JSON 和 mock 模式保证现场稳定。系统已经完成 Qwen `qwen-plus` 的 OpenAI-compatible 真实调用验证，下一步将扩大真实模型专项样本，并继续扩展 BGE 向量检索和更多航空材料专题。

## 动态追问替换讲稿（插入 4:20-5:05）

现在进入启发式追问工作台。我输入一个不在固定题库中的问题：为什么在 60 N、160 m 往复摩擦工况下，不能只凭磨损形貌就断定热氧老化是主导机制？系统带入当前本科生画像和诊断薄弱点，先完成材料路由，再由 Elasticsearch 检索精确工况和相关机理证据。

本轮回答不是孤立生成。启发式讲解 Agent 按本科生能够理解的层级组织证据链，审核纠偏 Agent 检查引用是否来自本次检索，并限制由单一形貌直接推断完整机理。最后，路径决策 Agent 给出补充案例、启发式追问和可执行记录任务。页面同时展示证据 ID、知识来源和限制说明。

当前页面会如实标注生成模式。只有录屏前使用同一问题预检成功，并且真实模型调用通过结构与证据校验时，才显示“真实 LLM 生成”；模型未配置、超时或输出不合格时自动使用模板兜底，因此外部服务波动不会中断比赛演示。异步进度区还会持续显示当前步骤和耗时，观众能够确认系统没有卡住。
