## 4. 复核边界

- 50 条核心用例已有项目团队领域专家组电子确认，属于内部复核证据。
- 真实 Qwen 的 6 条代表性场景已完成机器检查，仍建议安排外部专家盲审抽样。
- 正式材料如使用“专业正确率”“幻觉率”“难度适配准确率”等表述，应同时说明样本量、评分规则、复核主体和证据路径。
- 不应把 `56 passed`、`74 passed`、`107 passed` 或 `108 passed` 继续作为当前版本口径。

## 5. 更新规则

1. 先运行后端测试、前端构建和对应专项评测。
2. 更新 `competition_baseline.json`。
3. 运行 `python scripts/check_competition_baseline.py`。
4. 同步 PPT、录屏讲稿和提交包副本。
