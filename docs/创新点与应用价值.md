# 创新点与应用价值

## 一、主要创新点

### 1. 面向航空工程材料损伤分析的垂直知识证据体系

系统不是简单堆放 JSON 文本，而是建立“原始资料—Markdown 解析—知识切片—索引清单—Elasticsearch 检索—证据 ID 引用”的完整知识库构建流程。知识内容覆盖航空轮胎热氧老化与摩擦磨损、航空刹车高温摩擦与失效、复合材料冲击损伤与无损检测，并将实验工况、图像、定量记录、适用边界和来源定位共同纳入证据链。当前共管理 1,766 条切片、4 个团队实验专题和 53 项已审核实验资产。

### 2. 六 Agent 协同生成与交叉审核闭环

系统将学情诊断、材料路由、专业检索、资源生成、审核纠偏和路径决策拆分为六个职责明确的 Agent。每个步骤输出输入摘要、处理结果、置信度和 evidence IDs，形成“分析—生成—校验—决策”的可视化闭环。ReviewAgent 不仅检查语言形式，还核验结论与本轮证据的一致性、工况适用范围、资源难度和实操安全边界，必要时驳回候选结果并使用证据模板重生。

### 3. 学情画像驱动的差异化资源与动态决策

系统综合学习者类型、专业背景、自评基础、学习目标和诊断表现决定内容结构。本科生侧重现象解释和基础概念，材料研究生侧重机理、变量控制和证据链，机务维修新员工侧重检查流程、判读边界和维护规范。系统生成个性化讲义、实操指南、分阶测试题和案例任务，并在反馈测试后输出降维解释、继续巩固、补充案例或进阶挑战，实现资源和学习路径的持续更新。

### 4. 科研实操、精确工况检索与损伤判读结合

系统把专业训练从概念记忆延伸到实验记录和工程判断。以航空轮胎为例，可检索 60 N、160 m 等精确往复摩擦工况，并关联载荷—距离趋势、代表性形貌、磨损记录、证据 ID 和限制说明。系统明确区分实验观察、参数事实、机理推断和维护建议，避免由单张形貌或单次记录直接推出确定性损伤结论。

### 5. 真实 Qwen 动态问答与稳定兜底并存

系统已接入 OpenAI-compatible LLM 客户端，并完成 Qwen `qwen-plus` 代表性场景验证。开放追问会携带当前页面、学习者画像、诊断薄弱点和 RAG 证据进入多 Agent 子流程；模型输出经过证据闭合与审核规则校验。主训练资源默认使用证据约束模板，以缩短等待并保持录屏稳定；当模型、数据库或 Elasticsearch 不可用时，系统分别回退模板和本地 JSON，不中断完整训练流程。

### 6. 可部署、可观察、可验证的工程实现

React + Vite 前端展示系统状态和 Agent 实时进度，FastAPI 提供统一 REST API，MySQL 保存学习过程，Elasticsearch 管理领域证据。`/api/health` 可查看当前数据、检索和模型模式；异步任务展示当前步骤、已用时间和结果状态。项目包含 50 条核心测评用例、专项检索与问答测试、专家复核模板、部署脚本和脱敏打包脚本，方便评委复现和核验。

## 二、应用价值

### 1. 航空工程材料课程辅助教学

教师可将系统用于课前诊断、课堂案例分析和课后巩固，为不同基础学生提供难度匹配的材料与路径，减少统一教材难以覆盖个体差异的问题。

### 2. 科研入门与实验前训练

研究生和科研训练新手可学习如何从损伤现象建立机理假设，如何记录试验工况、组织表征证据并识别推断边界。实操指南和案例任务能够在正式实验前提供结构化预习。

### 3. 航空维修岗位案例训练

机务维修学习者可围绕损伤判读、检查流程、记录规范和安全边界开展训练。系统明确区分教学建议与适航维修结论，具体机型仍以现行制造商批准资料和单位程序为准。

### 4. 教学过程数据沉淀与复核

MySQL 可持续保存诊断、Agent 决策、生成资源、学情报告和反馈记录，教师能够查看学习过程，而不仅关注一次测试分数。导出的报告可用于教学复盘、科研训练记录和比赛验收。

### 5. 向更多航空材料与智能能力扩展

现有数据结构和 Agent 编排可迁移到航空涂层、金属疲劳、密封材料老化和复合材料修理等方向。后续可接入本地 BGE embedding、Elasticsearch kNN、更多公开或授权实验资料，以及更大规模的真实学习者效果验证。
