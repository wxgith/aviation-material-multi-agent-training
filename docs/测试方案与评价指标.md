# 测试方案与评价指标

## 1. 测试目标

验证系统是否满足比赛要求中的垂直领域知识生成、多智能体协同、个性化资源生成、专业审核、学情报告和反馈迭代能力。

## 2. 测试数据构成

测试数据包括：

- 3 组学习者画像；
- 3 个材料方向；
- 15 道诊断题；
- 1,766 条已索引知识片段，其中包含 17 条人工整理基础片段；
- 50 条评测用例；
- 人工专家复核表。

## 3. 学习者画像

- 本科低年级学生：基础概念薄弱，需要降维解释。
- 材料方向研究生：需要深入机理、表征和科研分析。
- 机务维修新员工：关注检查流程、维护判读和实操规范。

## 4. 领域知识库切片

知识库覆盖：

- 航空轮胎：热氧老化、滑动磨损、裂纹剥落、耦合损伤、实操检查。
- 航空刹车片：高温摩擦、热衰退、氧化裂纹、失效机理、实操训练。
- 飞机复合材料板：冲击损伤、分层、无损检测、损伤扩展、实操任务。

## 5. 50 条测试用例设计

核心测评集保留 50 条平衡用例；另在 `evaluation/eval_cases_multidimensional.json` 中增加 10 条多维证据用例，覆盖事故报告、维修规范、实验变量、运行记录、检测方法对比和来源多样性。`evaluation/literature_evidence_eval_cases.json` 再增加 10 条专项回归，验证 5 张已人工复核文献实验卡在真实 Elasticsearch 中的来源命中、证据可追溯和边界说明。增强用例不改变原 50 条基线统计，可单独用于答辩展示。

`evaluation/eval_cases.json` 包含 50 条测试用例：

- 学情诊断测试：10 条；
- 知识检索测试：10 条；
- 个性化资源生成测试：10 条；
- 审核纠偏测试：10 条；
- 反馈迭代测试：10 条。

每条用例包含：

- `id`
- `test_type`
- `learner_profile`
- `domain`
- `input`
- `expected_key_points`
- `expected_agent_steps`
- `expected_next_action`
- `pass_criteria`

## 6. 检索命中率

用于评估 RetrievalAgent 是否命中期望证据片段。

```text
检索命中率 = 命中期望证据的用例数 / 知识检索测试用例数
```

## 7. 核心知识点覆盖率

用于评估生成资源是否覆盖测试用例期望关键点。

```text
核心知识点覆盖率 = 已覆盖关键点数量 / 期望关键点总数
```

## 8. 幻觉率

用于评估专业断言是否有知识依据。

```text
幻觉率 = 无依据或错误断言数 / 抽检专业断言总数
```

## 9. 难度适配准确率

用于评估资源难度是否匹配画像和诊断水平。

```text
难度适配准确率 = 难度匹配资源数 / 抽检资源总数
```

## 10. Agent 完整率

用于评估每次管线是否完整输出 6 个 Agent 步骤。

```text
Agent 完整率 = 完整输出 6 步的会话数 / 会话总数
```

## 11. 反馈决策准确率

用于评估反馈测试后的 next_action 是否符合规则。

```text
反馈决策准确率 = next_action 正确的反馈用例数 / 反馈测试用例数
```

规则：

- < 50%：降维解释；
- 50%-74%：补充案例；
- 75%-89%：继续巩固；
- >= 90%：进阶挑战。

## 12. 人工专家复核流程

1. 选择评测用例；
2. 运行系统并导出报告；
3. 检查 Agent 步骤和 evidence_ids；
4. 对照 `knowledge_corpus/index_manifest.json`；
5. 使用 `evaluation/expert_review_form.md` 记录问题；
6. 汇总到 `evaluation/eval_results.md`。

### 官方高档验收阈值

| 专业指标 | 目标值 | 当前状态 |
| --- | ---: | --- |
| 核心知识点覆盖率 | >= 90% | 专家确认 100%（110/110） |
| 专业幻觉率 | < 5% | 专家确认 0%（0/200） |
| 画像—资源难度适配准确率 | >= 85% | 专家确认 100%（50/50） |

自动测试只验证流程、结构、规则和证据绑定；专业指标来自独立专家确认记录，机器代理值继续保留用于审计。三组完整输入输出样例位于 `evaluation/submission_examples/`，满足差异化学习者测试数据的可复核要求。
