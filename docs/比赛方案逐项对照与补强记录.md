# 比赛方案逐项对照与补强记录

## 一、核对范围

本记录依据官方《领域知识个性化生成与多智能体协同决策系统研究比赛方案》逐项核对当前系统。核对重点包括功能要求、评分维度、量化指标、测试数据和提交材料，不以概念架构替代可运行证据。

| 官方要求 | 当前实现 | 可复核证据 | 状态 |
| --- | --- | --- | --- |

## 四、官方量化门槛

| 指标 | 官方高档要求 | 当前证据 | 当前结论 |
| --- | ---: | --- | --- |
| 专业幻觉率 | < 5% | 结构化 evidence_ids、越界拦截、专家复核工作簿 | 专家确认 0%（0/200） |
| 画像—资源难度适配准确率 | >= 85% | 三类画像差异化策略、难度轨迹与 50 条逐项评分 | 专家确认 100%（50/50） |
| 核心知识点覆盖率 | >= 90% | 50 条核心用例、110 个期望关键点与专家确认记录 | 专家确认 100%（110/110） |
| 学习者画像组数 | >= 3 组 | 本科生、材料研究生、机务维修新员工 | 已满足 |
| 测试用例 | >= 50 条 | 核心用例 50 条，另有多维、实验、维修专项回归 | 已满足 |
| 真实领域数据 | 应包含真实领域知识与测试数据 | 公开论文/官方维修资料、授权团队实验资产、SQL 学习记录 | 已满足原型级要求，专业结论仍受证据边界约束 |

## 五、差异化完整样例

官方方案要求至少提供两组差异化学习者的画像输入、Agent 中间数据和最终生成资源。项目已生成三组完整样例：

- `evaluation/submission_examples/undergrad_basic_tire_complete_example.json`
- `evaluation/submission_examples/grad_materials_brake_complete_example.json`
- `evaluation/submission_examples/maintenance_new_composite_complete_example.json`

每组均包含画像、诊断提交与结果、6 个 Agent 步骤、4 类资源和学情报告。可在后端运行以下命令重新生成：

```powershell
python -m app.evaluation.submission_examples_runner
```
