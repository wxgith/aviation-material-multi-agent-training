# 录屏彩排清单

本清单用于正式录制前完成一次 10 分钟内的稳定预演。推荐使用 SQL + Elasticsearch 工程模式，真实 LLM 仅在录制前已连续验证成功时展示；任何网络或模型异常都允许自动回退模板生成。

## 1. 启动前

- [ ] 接通电源，关闭系统通知、聊天软件弹窗和自动更新。
- [ ] 屏幕分辨率设为 1920x1080，浏览器缩放 100%。
- [ ] 打开 Docker Desktop，等待引擎状态稳定。
- [ ] 确认录屏画面不出现 `.env`、API Key、数据库密码或个人隐私。

## 2. 一键启动

```powershell
cd D:\agents
.\scripts\start_project.ps1 -Headless -NoBrowser
.\scripts\project_status.ps1
```

- [ ] `report-mysql` 与 `agents-es` 为运行状态。
- [ ] 后端显示 SQL、ES 已连接，异步任务 API 兼容。
- [ ] 前端显示 `READY`。
- [ ] 手工打开 `http://127.0.0.1:8000/api/health` 和 `http://127.0.0.1:5173`。

## 3. 数据与模型预检

- [ ] ES 索引数量为 1,766。
- [ ] 主案例能命中 Elasticsearch 证据。
- [ ] 工程案例能显示 60 N、160 m、证据 ID、趋势图、图像和限制说明。
- [ ] 若展示 Qwen，先完成一次预设问题调用，确认耗时和返回结构正常。
- [ ] Qwen 未通过预检时关闭 `LLM_ENABLED`，全程按 mock 兜底口径讲解。

## 4. 正式路线

- [ ] 展示健康检查和首页系统状态。
- [ ] 加载本科生热氧老化主演示案例并提交诊断。
- [ ] 展示异步处理进度、当前 Agent、预计剩余时间和每步耗时。
- [ ] 展示六 Agent、ES 证据、四类资源、审核纠偏、报告导出和反馈迭代。
- [ ] 加载 60 N、160 m 工程检索案例，重点展示精确工况与证据边界。
- [ ] 用准备好的截图快速展示 DBeaver、ES 数量、116 passed、全局助手 JSON/ES 双模式 39/39、真实 Qwen 6/6 和前端 Build。

## 5. 时间控制

| 段落 | 目标时长 |
| --- | ---: |
| 工程状态与首页 | 50 秒 |
| 主案例闭环 | 5 分 30 秒 |
| 工程检索案例 | 1 分 40 秒 |
| 数据与测试证据 | 40 秒 |
| 总结 | 20 秒 |

总时长目标为 9 分 00 秒至 9 分 30 秒，给页面加载和口误保留余量。

## 6. 失败切换

- [ ] LLM 超时：等待自动 fallback，说明外部模型失败不会中断闭环。
- [ ] ES 异常：切换 JSON fallback，并展示已有检索证据截图。
- [ ] MySQL 异常：切换 JSON 数据模式，继续完成演示。
- [ ] 页面异常：先执行 `.\scripts\project_status.ps1`，再刷新；不要现场重建索引。
- [ ] 录制结束后执行 `.\scripts\stop_project.ps1`，Docker 可继续保持运行。
