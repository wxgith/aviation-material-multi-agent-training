# 界面视觉规范

## 1. 设计定位

系统界面定位为“航空材料训练任务控制台”，强调可信、严谨、可扫描和可操作。首页突出当前工程运行状态与稳定演示入口，训练页面突出任务阶段、证据链、审核状态和下一步操作，不采用普通聊天产品或营销落地页的视觉结构。

## 2. 色彩体系

| 语义 | 色值 | 用途 |
| --- | --- | --- |
| 石墨深色 | `#101f2a` | 主导航与工程环境背景 |
| 航空蓝 | `#176fa6` | 主要操作、当前步骤、核心信息 |
| 青绿色 | `#16856b` | 已连接、已通过、已确认 |
| 琥珀色 | `#d98432` | 实验依据、检索证据、需注意信息 |
| 钢蓝色 | `#416f9a` | 复合材料、审核与结构化信息 |
| 风险红棕 | `#b34d45` | 错误、驳回、风险提示 |
| 冷灰画布 | `#f3f6f8` | 页面背景，降低长时间阅读疲劳 |

颜色必须表达稳定语义，不能只作装饰。同类状态在不同页面保持一致。

## 3. 页面结构

1. 左侧导航按“系统总览”和“训练闭环”分组，当前页面使用高对比状态和左侧指示线。
2. 顶部工具栏固定展示当前页面和运行环境，减少录屏时的口头解释成本。
3. 首页首屏保留真实实验形貌作为背景，但将核心操作直接放在首屏内。
4. 系统状态采用紧凑指标网格，按数据、检索、模型、评测等语义分色。
5. 长页面遵循“概览、重点、证据详情”的阅读顺序，详细结构化输出默认折叠。

## 4. 组件规则

- 主按钮只用于当前流程的首要动作，例如“加载演示案例”和“提交诊断并启动 Agent”。
- 次按钮用于切换入口和辅助操作；下载、搜索、刷新等操作必须配套 Lucide 图标。
- 卡片圆角不超过 `7px`，避免娱乐化和过度柔和。
- Agent 时间线按阶段使用航空蓝、青绿、琥珀和钢蓝区分，但状态文字仍作为必要的冗余编码。
- 证据 ID、会话 ID 和工程参数使用等宽或数字等宽样式，支持快速核对。
- 动效限于页面进入、悬停和任务进度，不使用无功能意义的持续动画。

## 5. 响应式要求

- `820px` 以下将侧边栏转换为横向导航，隐藏分组标签，保留全部入口。
- `580px` 以下将表单、卡片、状态指标和主操作改为单列。
- 长证据 ID、会话 ID 和专业术语必须允许换行，不能撑破容器。
- 移动端首屏按钮采用整行布局，避免触控目标过小。

## 6. 参考规范

- [Ant Design 数据可视化页](https://ant.design/docs/spec/visualization-page-cn/)：采用“概览第一、聚焦过滤、按需查看详情”的信息组织原则。
- [Ant Design 详情页](https://ant.design/docs/spec/detail-page/)：采用直接、清晰、简洁的信息分组方式。
- [Elastic Dashboard Good Practices](https://eui.elastic.co/v106.0.0/docs/dataviz/dashboard-good-practices/)：按行组织相关信息，并保证图表和指标具备稳定比例。
- [Carbon 2x Grid](https://carbondesignsystem.com/elements/2x-grid/usage/)：参考产品型和高密度界面的栅格与最大宽度策略。

本项目只吸收上述公开设计规范中的通用原则，不复制第三方模板代码、品牌资源或受限视觉资产。
