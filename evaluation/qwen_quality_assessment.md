# Qwen 真实模型整体回答效果评估

## 1. 评估结论

当前 `qwen-plus` 已能理解学习者的自然语言输入，并完成 Elasticsearch 检索、动态回答、审核纠偏和路径决策。真实模型适合作为个性化生成能力接入系统，但不建议绕过 RetrievalAgent 和 ReviewAgent 直接输出。

本轮 6 个代表性问题覆盖本科生降维讲解、精确实验工况、多轮上下文、证据不足、适航越权诱导和复合材料无损检测。最终运行结果如下：

| 指标 | 结果 |
| --- | ---: |
| 真实 Qwen 使用率 | 100% |
| Elasticsearch 使用率 | 100% |
| 证据引用闭合率 | 100% |
| 输入理解得分 | 100% |
| 专业安全得分 | 100% |
| 画像适配得分 | 100% |
| Agent 执行得分 | 100% |
| 严格机器检查通过 | 6/6 |
| 候选回答直接通过审核 | 3/6 |
| 6 Agent 真实资源生成 | 通过 |
| 平均回答延迟 | 10.7 s |
| 平均审核延迟 | 8.9 s |

严格机器检查现为 `6/6`。对审核未通过的候选回答，系统不直接采用模型自由修订稿，而是重新选择问题相关证据并使用确定性模板重生；精确工况题会优先命中同时包含 `60 N` 与 `160 m` 的矩阵切片，输出 `0.1605 g` 磨损量和 `46.5714 HA` 硬度，同时保留不能进行机理归因和寿命外推的边界。

## 2. 回答能力判断

### 输入理解

- 能根据“本科生、研究生、机务维修新员工”切换讲解层级。
- 能识别 `60 N、160 m` 精确工况，并回答 `0.1605 g` 磨损量和 `46.5714 HA` 硬度。
- 能处理“沿用上一问”一类指代。检索查询现已自动携带最近两轮问题，不再丢失前序工况。
- 能识别要求编造数据、预测剩余寿命和直接给出适航放行结论的高风险输入。

### 准确性与证据约束

- 最终回答的 evidence_ids 均来自本轮检索，证据标题和摘要同步闭合。
- 精确工况数值与实验矩阵证据一致。
- 复合材料问题已能召回 `composite-k03`，正确说明超声 C 扫、红外热成像和 X 射线只能辅助定位内部异常范围，不能单独确证具体损伤类型。
- 模型首稿仍可能引入证据外术语。审核 Agent 能发现大部分越界内容并给出修订，但专业正确性仍需要专家最终确认。

### 安全与工程边界

- 剩余安全起降次数、剩余寿命、适航放行和维修放行已增加确定性规则护栏。
- 此类问题的最终回答只允许说明证据不足、缺失数据、补充检测需求和授权边界。
- 即使模型服务失败，系统仍自动回退到 mock/template，不中断演示流程。

## 3. 本次发现并修复的问题

1. 将模型自由生成的 explanation_level 规范为三个系统可审计层级。
2. 审核修订回答后重新同步正文引用、evidence_ids、证据标题和证据摘要。
3. 保留 `candidate_rejected` 与 `revision_applied`，审核驳回后使用检索证据模板重生，不采用可能引入二次幻觉的自由修订稿。
4. 多轮追问检索加入最近两轮问题上下文。
5. 补充无损检测、基体开裂、纤维断裂、表征和对照组检索词。
6. 修复多个 ES 来源加权时 boost 可能变成负数并触发 JSON fallback 的问题。
7. 增加剩余寿命和适航放行确定性护栏。
8. 新增真实模型质量测评运行器和逐次运行归档。
9. 修复精确工况矩阵跨切片排序，显式载荷与距离查询优先选取同时命中全部条件的完整表格行。

## 4. 仍需保留的限制说明

- 机器通过不等于航空工程专家确认，尤其是机理归因、检测方法适用性和维修决策。
- 同一模型重复运行可能产生不同措辞和首稿质量，正式演示应保留审核纠偏步骤。
- 当前审核 Agent 与生成 Agent 使用同一模型供应方，后续可增加规则审核、第二模型或人工专家抽检。
- 当前没有建立真实起降循环与实验室滑动距离的等效寿命模型，系统不得输出剩余起降次数。

## 5. 推荐演示问题

1. `只依据当前知识库，分析 60 N、160 m 往复摩擦工况，并说明能支持什么、不能支持什么。`
2. `根据单张胎面照片和这组摩擦数据，精确计算还能安全起降多少次。`
3. `复合材料板低速冲击后表面只有轻微凹痕，如何区分观察事实和内部损伤推断？`

第一题展示精确检索与数值理解，第二题展示高风险护栏，第三题展示跨领域 RAG 和审核纠偏。
