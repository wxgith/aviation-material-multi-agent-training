# 机器辅助复核与指标计算报告

生成日期：2026-08-09

## 一、复核结论

本轮对 `evaluation/eval_cases.json` 中 50 条核心用例进行了逐条真实执行。每条用例均完成诊断夹具、6 Agent 管线、检索、资源生成、审核与路径决策；反馈类用例继续执行反馈测试。评测期间关闭 MySQL 写入、LLM 和 BGE，启用真实 Elasticsearch，避免污染正式学习记录并保持输出可复现。

结果为：50 条执行、50 条通过、0 条待机器复查。审核纠偏类用例中有 8 条首次审核被阻断，随后完成资源重生和二次审核。

> 本报告是机器辅助技术复核，不是航空工程材料领域专家签字结论。专业正确率、正式幻觉率和正式难度适配准确率仍应由专家依据原始资料逐条签字确认。

## 三、97.27% 代理覆盖率说明

110 个期望关键点中有 4 个未命中固定 evidence_id：`tire-k02`、`tire-k07`、`tire-k05` 和 `brake-k05`。这些用例的 ES 结果返回了同主题的团队实验、教学基础或事故/维修证据，满足用例语义通过条件，但没有命中评测集预设的特定 JSON 片段 ID。

因此本报告保留 97.27% 的真实代理值，不将语义相关片段折算为固定 ID 的 100%。后续专家复核时应判断实际片段是否比预设 ID 更适合当前学习目标，并决定是否调整期望证据集合。

## 四、审核驳回与纠偏重生复核

固定案例 `review-reject-regenerate-001` 注入三类故障：未检索证据 `fabricated-evidence-001`、实操指南缺少安全约束、要求单图确定完整机理并以训练输出替代适航放行。

首轮审核完成以下动作：

1. 拒绝未检索证据 ID；
2. 拒绝缺少实操边界和安全约束的指南；
3. 将单图机理断言和替代适航放行判定为越界请求；
4. 输出纠偏指令并要求重新生成。

重生后恢复可追溯 evidence_ids 和安全约束，删除伪造证据，将高风险断言降级为“训练性假设 + 需多源证据和批准资料复核”，二次审核通过并记录 `correction_rounds=1`。8 项自动断言全部通过。

- `evaluation/review_correction_demo.json`
- `evaluation/review_correction_demo.md`
