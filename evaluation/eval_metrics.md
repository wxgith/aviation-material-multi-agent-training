# 评价指标说明

## 1. 检索命中率

衡量 RetrievalAgent 返回的 `evidence_ids` 是否包含测试用例期望的核心知识片段。

```text
检索命中率 = 命中期望证据的用例数 / 知识检索测试用例数
```

## 2. 核心知识点覆盖率

衡量生成讲义、实操指南、测试题和案例任务是否覆盖 `expected_key_points`。

```text
核心知识点覆盖率 = 已覆盖关键点数量 / 期望关键点总数
```

比赛高档验收目标：`>= 90%`。该指标必须由领域专家判断语义是否真正覆盖，不能用关键词出现率替代。

## 3. 幻觉率

衡量生成内容中没有知识库依据、与 evidence_ids 不一致或超出训练系统边界的专业断言比例。

```text
幻觉率 = 被专家判定为无依据或错误的断言数 / 抽检专业断言总数
```

比赛高档验收目标：`< 5%`。无 evidence_id、与证据冲突、把假设写成事实或超出维修授权边界的断言均计入。

## 4. 资源难度适配准确率

衡量资源难度是否与学习者画像和诊断水平匹配。

```text
难度适配准确率 = 难度匹配的资源数 / 抽检资源总数
```

比赛高档验收目标：`>= 85%`。前端难度轨迹是规则映射可视化，最终准确率仍由三类画像的专家抽检结果计算。

## 5. Agent 完整率

衡量每次运行是否完整输出 6 个 Agent 步骤。

```text
Agent 完整率 = 完整输出 6 步的会话数 / 测试会话总数
```

## 6. 反馈决策准确率

衡量反馈正确率与 `next_action` 是否符合规则。

参考规则：

- 正确率 < 50%：降维解释
- 50% <= 正确率 < 75%：补充案例
- 75% <= 正确率 < 90%：继续巩固
- 正确率 >= 90%：进阶挑战

```text
反馈决策准确率 = next_action 符合预期的反馈用例数 / 反馈测试用例数
```
