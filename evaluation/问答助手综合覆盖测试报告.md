## 4. 本轮发现并修复

1. 全局助手补充口语化界面意图和学情询问，例如“咋开始”“我哪里不会”“接下来练什么”。
2. 无正式会话时，最近消息会作为临时上下文传入，支持“沿用上一问”类指代。
3. 前端向后端传递最近四条对话，并显示真实 LLM、模板 fallback 和审核驳回重生三种状态。
4. 审核 Agent 驳回真实模型候选后，不直接采用自由修订稿，改用已检索证据模板重生，降低二次幻觉风险。
5. 修复 `60 N / 160 m` 精确工况跨切片排序，优先选择同时命中全部条件的矩阵行；可确认值为磨损量 `0.1605 g`、硬度 `46.5714 HA`。
6. 真实模型延迟统计在审核重生后仍保留原候选调用耗时，避免误报为 0 ms。

## 5. 审核边界

- 机器检查验证输入理解、结构、证据闭合、关键词、安全规则和 Agent 流程，不等于航空工程专家对每次新生成文本的事实确认。
- 当前真实模型样本为 12 次代表性抽样，足以证明链路和主要场景可用，但不足以宣称模型在任意问题上都准确。
- 正式演示建议保留真实 Qwen，同时保留 mock/template 一键回退。网络或模型不稳定时，切换 fallback 不影响诊断、资源、报告和反馈闭环。
- 不允许系统根据单张图片输出确定失效机理、剩余寿命、剩余起降次数或适航放行结论。
