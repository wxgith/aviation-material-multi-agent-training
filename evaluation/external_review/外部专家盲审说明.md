# 外部专家盲审说明

## 1. 目的

由项目团队之外、具备航空工程材料、摩擦磨损、复合材料或航空维修背景的专家，对真实 Qwen 代表性输出进行匿名复核，验证专业正确性、证据一致性、边界合规性和难度适配性。

## 2. 评审材料

- `blind_review_cases.json`：6 条匿名案例，包含学习者画像、问题、最终答案、证据片段、边界和训练任务。
- `external_review_scores.csv` 或 `外部专家盲审评分表.xlsx`：专家评分入口。
- `blind_case_key_private.json`：项目组内部映射，不发送给评审专家。

## 3. 盲审规则

1. 专家评分前不得查看生成模式、机器检查结果或 ReviewAgent 是否驳回过候选。
2. 每项使用 1 至 5 分：1 分严重不符合，3 分基本可用但需修改，5 分准确且边界清晰。
3. `hallucination_flag` 仅在答案出现无依据事实、错误数值、错误引用或越权结论时记为 1。
4. 结论选择“接受、修改后接受、驳回”之一，并写明可复核理由。
5. 建议至少邀请 2 名独立专家；出现分歧时由第三名专家仲裁。

## 4. 汇总指标

- 专业正确率：结论为“接受”或“修改后接受”且修订完成的案例数 / 总案例数。
- 证据一致性均分：所有案例证据一致性评分的平均值。
- 幻觉率：`hallucination_flag=1` 的案例数 / 总案例数。
- 难度适配准确率：难度适配评分不低于 4 分的案例数 / 总案例数。

## 5. 签署要求

评审人填写姓名、单位或职称、日期，并在最终汇总页签字或使用可核验电子签名。项目不得代签，也不得将未完成的外部盲审写成“专家已确认”。
